# Coq AstroNvim Configuration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Configure AstroNvim v6 for Coq proof assistant development with coqtail (interactive stepping), coq-lsp (LSP features), and treesitter syntax highlighting.

**Architecture:** One new file `lua/plugins/coq.lua` holds coqtail and the astrolsp override for coq-lsp. `lua/plugins/treesitter.lua` is activated with the `coq` parser added. coq-lsp is opam-managed (not Mason), so it is registered via astrolsp's `servers`/`config` tables using the function form to avoid clobbering existing config.

**Tech Stack:** AstroNvim v6, whonore/coqtail, coq-lsp (opam), nvim-treesitter (via astrocore)

### Task 2: Create coq.lua with coqtail and coq-lsp

**Files:**
- Create: `lua/plugins/coq.lua`

- [ ] **Step 1: Create the file**

```lua
---@type LazySpec
return {
  -- Interactive Coq proof stepping with <Leader>c* keybindings.
  -- g:coqtail_nomap disables the default ,c* mappings.
  {
    "whonore/coqtail",
    ft = "coq",
    init = function()
      vim.g.coqtail_nomap = 1
    end,
    config = function()
      local function set_coq_maps(buf)
        local map = function(lhs, rhs, desc)
          vim.keymap.set("n", lhs, rhs, { buffer = buf, desc = desc })
        end
        map("<Leader>cs", "<Cmd>CoqStart<CR>", "Start Coq")
        map("<Leader>cQ", "<Cmd>CoqStop<CR>", "Stop Coq")
        map("<Leader>cn", "<Cmd>CoqNext<CR>", "Coq step forward")
        map("<Leader>cu", "<Cmd>CoqUndo<CR>", "Coq step back")
        map("<Leader>cj", "<Cmd>CoqToLine<CR>", "Coq advance to cursor")
        map("<Leader>cG", "<Cmd>CoqJumpToEnd<CR>", "Coq cursor to end of checked")
      end
      -- Autocmd for all subsequent coq buffers
      vim.api.nvim_create_autocmd("FileType", {
        pattern = "coq",
        group = vim.api.nvim_create_augroup("CoqtailMappings", { clear = true }),
        callback = function(ev) set_coq_maps(ev.buf) end,
      })
      -- Also apply to the buffer that triggered the plugin load
      if vim.bo.filetype == "coq" then
        set_coq_maps(vim.api.nvim_get_current_buf())
      end
    end,
  },

  -- Register coq-lsp with AstroNvim's LSP system.
  -- coq-lsp is opam-managed; install with: opam install coq-lsp
  -- If the binary is absent, nvim-lspconfig silently skips attachment.
  {
    "AstroNvim/astrolsp",
    opts = function(_, opts)
      opts.servers = opts.servers or {}
      table.insert(opts.servers, "coq_lsp")
      opts.config = opts.config or {}
      opts.config.coq_lsp = {
        cmd = { "/home/loic/.opam/default/bin/coq-lsp" },
      }
      return opts
    end,
  },
}
```

- [ ] **Step 2: Verify Lua syntax**

Run: `luac -p ~/.config/nvim/lua/plugins/coq.lua`
Expected: No output (silent = success).

- [ ] **Step 3: Confirm the file content is correct**

Read the file and verify:
- `vim.g.coqtail_nomap = 1` is set in `init`
- All 6 keybindings are present with correct commands
- `coq_lsp` is in `opts.servers`
- `cmd` points to `/home/loic/.opam/default/bin/coq-lsp`
- `opts` is a function (not a plain table) to avoid clobbering existing astrolsp config
